# codeforces-scraper

### A simple Python script to scrape problem statements from Codeforces.

### install the required libraries
```bash
pip install -r requirements.txt
```


### Usage
- Change Headers, Cookies, and CSRF token in `problemset.py` file.

- Adjust the range of problem IDs in the `for` loop in `scraper_final.py`.

- Run the scraper:
```bash
python scraper_final.py
```
